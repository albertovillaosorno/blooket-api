# Direct browser image search

When the requested image is not in the local library, use an admitted browser or
search capability with concrete visual terms. Prefer a few strong candidates to
repeated broad searches.

Analyze candidate pixels immediately when available. Separate visible facts from
inference and from source metadata. Note obvious text or watermarks and whether
the image clearly communicates the requested educational concept.

Keep provider, source page, title, creator, and license metadata when readily
available. Missing rights metadata is unknown; do not invent a rights claim.
