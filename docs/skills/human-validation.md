# Human validation

CAPTCHA, security challenge, unfamiliar login, organization selection, consent,
browser permission, and similar prompts are human-validation boundaries.

Preserve the checkpoint, explain the exact legitimate local action required, and
wait for the teacher to confirm completion. Then observe the session and fresh
remote state before continuing. Never replay an ambiguous mutation
automatically.

A challenge shown through localhost is still a provider challenge. Do not solve,
bypass, outsource, forge, suppress, or automatically complete it.
