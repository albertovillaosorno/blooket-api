# Human validation

Provider verification can complete without human input. Let the product's
bounded passive observation finish, then require fresh authenticated session
and remote-state evidence. A redirect alone never confirms authentication or
publication.

When the product still reports a human-action-required state, preserve the
checkpoint and explain the exact legitimate local action. Interactive
verification follows the active controller's confirmation rules. Unfamiliar
login, organization selection, consent and browser permission retain their
actual human boundaries.

Never bypass security protections, automatically choose an organization, or
replay an ambiguous mutation. After a legitimate human action, observe the
session and fresh remote state before continuing.
