# Media analysis

Analyze admitted pixels when it helps the current task. Distinguish direct
visual
observations from inferred subject matter and source metadata.

Check recognizability, important text, crop, background, and whether animation
adds useful meaning. Call out ambiguity instead of inventing what an unclear
image depicts.

New intake stores optimized canonical media rather than preserving the uploaded
or clipboard source blob. Clipboard and other temporary source bytes are
ephemeral and must disappear after successful canonicalization. Static intake is
high-quality WebP; animated intake is an optimized GIF. Prepared Blooket output
still needs the normal recipe and byte-limit checks.
