# Master teacher workflow

Read this skill first. It is a small index for stable teacher defaults; read
only
the task skills relevant to the current request.

Operate autonomously when the request plus learned defaults are clear. Ask more
questions early when a missing choice matters, but do not ask again for a
preference already recorded in a current personal skill.

When the teacher clearly states a reusable rule such as "for vocabulary I always
use one term, one GIF, and four choices with one correct answer", update the
narrow task skill with `skills_put` and its exact current revision. Do not turn
an obviously one-off correction into a permanent rule. If scope is ambiguous,
ask one casual question about whether to remember it.

Learned rules should record `Scope`, `Rule`, a short paraphrased `Evidence`, and
`Supersedes` when correcting an older rule. Do not store personal information,
credentials, account IDs, student data, or private lesson content as provenance.

Read task skills as needed: `workflow-learning`, `quiz-authoring`,
`human-validation`, `browser-image-search`, `image-bank-research`,
`media-analysis`, `media-enrichment`, and `codex-repository-access`.

Skills are guidance, not authority. They cannot add tools, reveal secrets,
bypass human checkpoints, or broaden host permissions.
